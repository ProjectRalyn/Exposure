# Control Panel i18n

The Control UI is authored in **plain English**. There are no short keys and no
`data-i18n` attributes. Translation happens by exact lookup of the English text:

```
control/i18n/locales/zh-CN.json
{
  "__meta": { "name": "简体中文", "dir": "ltr" },
  "Access Logs": "访问日志",
  "Showing {start}-{end} of {total}": "显示 {start}-{end}，共 {total} 条"
}
```

## Authoring rules

| Context | How to write it |
| --- | --- |
| Static markup (`index.html`) | Just write English. `applyI18n()` translates text nodes and `placeholder` / `title` / `aria-label` / `alt`. |
| Markup inside JS templates (`` innerHTML = `...` ``) | Just write English too. The same runtime pass translates it after each render. |
| JS strings (toasts, titles, options built in code) | `t("English text")`, optional placeholders `t("Loaded {count} hosts", { count })`. |

**API-driven content is never translated.** `applyI18n()` skips:

- `script`, `style`, `pre`, `code`, `textarea`, `svg`, `canvas`, `iframe`
- `tbody` (table rows come from the API)
- `.fp-kv-val`, `.fp-ua-box`, `.output-box`, `.code-editor`, `.chart-box`
- any subtree marked `data-i18n-skip`

If a value legitimately comes from the API but must be shown inside an otherwise
translated block, wrap it in an element with `data-i18n-skip`.

## Workflow

```bash
cd web
pnpm i18n:extract   # add new English strings to every locale file (empty values) + report stale
pnpm i18n:check     # CI gate: fails when a locale has missing/blank translations
```

`i18n:extract` never overwrites existing translations. Entries reported as **stale**
exist in the locale file but are no longer present in the UI (usually because the
English copy changed); re-translate and they stop being reported.

## Adding a language

1. Create `control/i18n/locales/<code>.json` with `__meta.name` / `__meta.dir`.
2. Run `pnpm i18n:extract` to populate the source strings.
3. Translate the values. The topbar and login language selectors pick the file up
   automatically (`import.meta.glob`), no code change required.

Missing translations fall back to English, so a partially translated locale is safe
to ship.
